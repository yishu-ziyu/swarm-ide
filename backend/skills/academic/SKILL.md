# 学术写作 Agent

## How to Help

这个 Skill 帮助用户进行学术写作。当你需要：

- 撰写研究论文或报告
- 规范化和校对引用格式
- 构建逻辑严密的论证结构
- 进行文献综述
- 撰写摘要和结论

调用这个 Skill 获取写作指导。

## Academic Writing Principles

### Principle 1: 清晰性 (Clarity)

> "If you can't explain it simply, you don't understand it well enough." — Albert Einstein

学术写作的首要原则是清晰表达：
- 使用简洁、准确的语言
- 避免模糊术语和不必要的复杂句式
- 每个段落只表达一个核心观点

### Principle 2: 结构化 (Structure)

清晰的结构帮助读者跟随论证：

```
论文结构（标准格式）：
1. 摘要 (Abstract) - 200-300字
2. 引言 (Introduction) - 研究背景、问题、贡献
3. 文献综述 (Literature Review) - 现有研究分析
4. 方法论 (Methodology) - 研究方法说明
5. 发现/结果 (Findings/Results) - 核心发现
6. 讨论 (Discussion) - 发现的意义
7. 结论 (Conclusion) - 总结和未来方向
8. 参考文献 (References)
```

### Principle 3: 论证逻辑 (Argumentation)

论证必须严密：
- 论点（Claim）：你的主张
- 论据（Evidence）：支持主张的证据
- 推理（Warrant）：连接论据和论点的逻辑

```
论证类型：
1. 演绎推理：从一般到特殊
2. 归纳推理：从特殊到一般
3. 类比推理：通过相似情况推断
4. 反例论证：通过否定来证明
```

## Citation Management

### 引用追踪系统

维护一个引用数据库：

```
引用ID格式：[类型]-[年份]-[序号]
示例：
- 期刊论文：JP-2023-001
- 会议论文：CP-2023-001
- 网络资源：WB-2023-001
- 书籍：BK-2023-001
```

## Writing Templates

### 模板1: 摘要 (Abstract)

```
【结构】
背景（1句）：研究问题的上下文
目的（1句）：研究的主要目标
方法（1-2句）：采用的研究方法
结果（1-2句）：主要发现
结论（1句）：研究意义

【示例】
随着深度学习在医疗影像中的应用增长，数据隐私保护成为关键挑战。
本研究提出一种基于联邦学习的隐私保护框架，在保证数据不出本地的前提下
实现多中心医疗影像的协同训练。我们在3个公开数据集上验证了该方法，
分类准确率达到 95.2%，同时确保了患者数据的隐私安全。
```

### 模板2: 引言 (Introduction)

```
【结构】
第1段 - 背景：介绍研究领域的一般背景
第2段 - 问题：具体说明研究问题及其重要性
第3段 - 现有方案：概述现有解决方案及其局限
第4段 - 贡献：明确本文的主要贡献

【示例】
深度学习在医学影像诊断领域取得了显著进展（背景）。
然而，由于医疗数据的隐私敏感性，多中心协作训练面临重大挑战（问题）。
现有方案如数据匿名化或联邦学习虽有一定效果，但存在信息泄露风险或通信开销大的问题（现有方案）。
本文提出一种基于差分隐私的联邦学习框架，在理论上保证数据隐私安全（贡献）。
```

### 模板3: 结论 (Conclusion)

```
【结构】
第1段 - 总结：概括研究的主要发现
第2段 - 意义：阐述研究的理论和实践意义
第3段 - 局限：承认研究的局限性
第4段 - 未来：指出未来研究方向

【示例】
本研究提出了一种隐私保护的医疗影像协同训练框架（总结）。
实验结果表明，该方法在保证数据隐私的同时，达到了与集中式训练相当的准确率（意义）。
本研究存在以下局限：仅在影像数据上验证，未涵盖其他医疗数据类型（局限）。
未来工作将探索该框架在更多医疗场景中的应用，以及隐私预算的优化（未来）。
```

## Academic Phrases Library

### 引用现有研究

```
根据 Smith 等人(2023)的研究...
Smith 等人(2023)指出...
先前的研究表明...(Smith et al., 2023)
近年来，研究者开始关注...(Johnson, 2022)
```

### 表达观点

```
我们认为...
本文主张...
研究表明...
证据表明...
```

### 表示对比

```
然而...
与此相反...
相比之下...
尽管...
虽然...
```

### 表示因果

```
因此...
结果...
导致...
由于...
由此可见...
```

### 表示强调

```
重要的是...
关键的是...
值得注意的是...
本质上...
```

## Proofreading Checklist

完成写作后，检查以下内容：

- [ ] 语法和拼写错误
- [ ] 句子是否简洁清晰
- [ ] 段落逻辑是否连贯
- [ ] 引用格式是否统一（APA/MLA/Chicago）
- [ ] 图表编号和标题是否正确
- [ ] 参考文献是否完整
- [ ] 学术用语是否准确
- [ ] 论证逻辑是否严密
