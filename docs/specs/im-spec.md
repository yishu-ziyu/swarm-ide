# IM 界面规格文档

## 概述

Swarm-IDE 采用三栏布局的 IM 界面，让 AI 协作像微信聊天一样直观，同时保持拓扑可视化。

## 栏位规格

### 左栏：对话列表（宽度：240px，可折叠）

**结构**：
- Workspace 根节点（不可删除）
- 树状展开/折叠的 Agent 列表
- 嵌套层级表示父子关系

**样式**：
- 背景：`#1a1a2e`
- 选中态：左侧蓝色边框 `#4a9eff`
- 悬停态：背景 `#252542`
- 运行中 Agent：绿色指示灯

**交互**：
- 单击 → 选中并在中间栏打开对话
- 右键 → Agent 操作菜单（重命名、终止、查看详情）
- `[+]` 按钮 → 创建新 Agent

---

### 中栏：聊天区域（弹性宽度）

**消息类型**：

| 类型 | 样式 |
|------|------|
| 人类消息 | 右对齐，蓝色气泡 `#4a9eff`，圆角 12px |
| AI 回复 | 左对齐，深灰气泡 `#2d2d44`，白色文字 |
| 系统消息 | 居中，浅色背景 `#16162a`，小字号 |

**Agent 卡片**（当 Agent 创建子节点时）：
```
┌─────────────────────────────────────────┐
│ 🤖 Agent-A                    [运行中]  │
│ ────────────────────────────────────── │
│ 我创建了三个子 Agent：                   │
│ • Research-Agent (市场研究)             │
│ • Tech-Agent (技术分析)                 │
│ • Product-Agent (产品策略)              │
└─────────────────────────────────────────┘
```

**底部工具栏**：
- `[Available Skills]` 按钮 → 打开 Skill 选择器
- 文本输入框（多行支持）
- `[发送]` 按钮 / `Cmd+Enter` 快捷键

---

### 右栏：Graph 拓扑图（宽度：320px，可折叠）

**节点样式**：
- 圆形节点，直径 48px
- 根节点（User）：蓝色边框
- Orchestrator：紫色填充 `#8b5cf6`
- 子 Agent：根据角色着色
- 运行中：脉冲动画

**连线样式**：
- 实线箭头表示消息流向
- 颜色：`#4a9eff`（可区分层级）
- 箭头指向接收方

**交互**：
- 点击节点 → 在中栏打开该 Agent 私聊
- 悬停节点 → 显示 Agent 名称和状态
- 缩放/平移 → 鼠标滚轮/拖拽

## 响应式行为

| 窗口宽度 | 行为 |
|----------|------|
| >1400px | 三栏完整显示 |
| 1000-1400px | Graph 栏可折叠 |
| <1000px | 只显示聊天区，侧边栏浮层 |

---

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Cmd/Ctrl + Enter` | 发送消息 |
| `Cmd/Ctrl + G` | 切换 Graph 栏 |
| `Cmd/Ctrl + S` | 切换侧边栏 |
| `Cmd/Ctrl + K` | 打开命令面板 |
| `Esc` | 收起当前面板 |

---

## 技术实现要点

### 布局引擎
- CSS Grid 三栏布局
- CSS Variables 统一颜色主题
- Flexbox 内部组件布局

### 状态管理
- 选中 Agent ID → 控制中间栏显示
- Graph 数据结构 → 邻接表表示节点关系
- 消息列表 → 按 Agent ID 过滤

### 性能考量
- Graph 节点过多时启用虚拟化
- 消息列表懒加载
- 树状列表虚拟滚动
